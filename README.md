## 物资与补给机制

保障车辆不再有无限物资。三类物资各有容量、装卸耗时与使用单位：

| 物资 | 单位 | 补给车容量 | 对应保障 |
| --- | --- | --- | --- |
| 航空燃油 | L | 2400 | 加油车 |
| 清洁耗材 | 份 | 40 | 清洁车 |
| 行李容器 | 件 | 60 | 行李车 |

核心规则：

- **仓库预约 ≠ 装车**：预约只登记预约占用，物资依次经历仓库装车 → 在途 → 现场卸货；保障车只能消费已经卸到机位现场缓存的数量。
- **两种补货策略**：集中补货（不低于车容 40%，无额外成本，减少空跑）与少量急送（任意数量、即时发运，计 −5 分成本，用来保住临近截止的航班）。远机位同样需要安排补给路线。
- **部分供给与等待续供**：物资不足时保障照常开工，耗尽后作业进入“等待续供”，车辆与机位服务位继续被占用；续供到位后自动恢复。
- **改派/取消与滞留区**：途中召回补给车或取消保障任务时，未使用物资随车回到可核查的滞留区，核验通过后才能重新入库，绝不直接加回仓库。
- **共用机坪资源**：补给车与保障车共用机坪交通，每个机位最多同时容纳 2 台车辆。
- **总账守恒**：仓库（含预约占用）+ 在途车载 + 现场缓存 + 滞留区 + 已消耗 = 初始库存。物资总账面板实时显示库存占压、在途与预计断供，并标注一次短缺会影响哪些离港航班；存档校验强制要求守恒，账目异常的存档不予恢复。
